# Setup

## Goal

Build a fast Android prototype in VS Code on Windows that can:
- capture speech-to-text
- speak text-to-speech
- simulate AI responses first
- later swap in Azure Speech and Azure/OpenAI integration

## Decisions

- OS: Windows
- Editor: VS Code
- App language: Kotlin
- UI: Jetpack Compose
- Build tool: Gradle
- JDK: OpenJDK 17
- Speech: Azure Speech later, local simulation first
- Repo path: `D:\\Code`

## Prerequisites

1. Git for Windows
2. OpenJDK 17 (Temurin recommended)
3. Android SDK
4. VS Code extensions for Kotlin/Gradle
5. Android device or emulator
